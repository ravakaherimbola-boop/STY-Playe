# STY Player — projet Android

Lecteur expérimental de styles Yamaha PSR avec interface sombre, sections INTRO 1 / VAR A-D / ENDING 1,
contrôles PLAY/STOP, tempo, chargement de SoundFont SF2 et moteur FluidSynth.

**État : prototype en développement.** La lecture dépend de la structure MIDI du fichier STY et d'une
SoundFont chargée par l'utilisateur. MuldjordKit n'est pas encore incluse dans le projet et l'égaliseur
graphique est présent mais pas encore relié au signal audio.

Pour compiler l'APK sans ordinateur, suivre `README-CLOUD-BUILD.md`.
